I built a student pass/fail prediction project in Python.I cleaned messy tabular data (missing values, invalid text, and bad categories), 
encoded the course column with One-Hot Encoding, and compared Logistic Regression and Random Forest using 5-fold Cross-Validation. 
Logistic Regression performed better (average accuracy 0.78 vs 0.73). On a held-out test set the model reached 0.81 accuracy.
